# FlottenManager Projekt

Ein kleines TypeScript-Projekt zur Verwaltung von Fahrzeugen (E-Scooter & E-Bikes).

## Funktionen

- Fahrzeuge hinzufügen & entfernen
- Alle Fahrzeuge anzeigen
- Verfügbare Fahrzeuge anzeigen
- Leere Fahrzeuge automatisch laden (<20% -> 100%)
- Preisberechnung pro Minute
- Wartungsmodus nach 5 Ausleihen

## Technologien

- TypeScript
- Node.js

## Starten

```bash
npx tsc
node dist/index.js
